# v0.1.0-alpha.1

> Date: 2026-04-29
> Status: Windows tester release candidate
> Scope: local Runtime-first validation loop, fake-adapter smoke path, CLI/MCP/TUI build verification.

## Release Goal

Give a Windows tester a reproducible checkout-to-smoke-test path:

```text
clone -> install -> typecheck/test/build -> start Runtime Server -> submit fake validation -> inspect status/events/evidence/result
```

This is not a production hardware release. It is a testable alpha for validating the local developer workflow, contracts, adapters, storage, and terminal-facing surfaces.

## Included

- Runtime Server HTTP API with local Fastify listener command.
- Safe fake-adapter startup path for Windows without attached hardware.
- Optional demo hand-written Plan for fake smoke validation.
- Contracts for validate/status/events/watch/evidence/result/intervention/capabilities.
- File-backed run state, event stream, evidence index, and final reply.
- Runtime execution through fake adapters and real adapter implementations in package code.
- CLI thin adapter for Runtime API.
- MCP thin adapter over Runtime API.
- TUI Run Cockpit fixture.
- LLM provider abstraction and disabled-by-default mock config.

## Recent Runtime Changes Included

- Observer duplicate rule trigger debounce.
- Runtime target state inferred from active step.
- Evidence windows passed into Observer.
- Rule-matched serial pattern events.
- Error rule matches routed to failure path.
- Pause/resume/cancel honored at plan boundaries.

## Not Included

- No Web UI.
- No installer or packaged binary.
- No Windows real-device certification yet.
- No multi-target scheduler.
- No distributed worker or external database requirement.
- No default real LLM calls; `configs/llm.yaml` is disabled by default.

## Verification Required Before Tag

- `pnpm --filter @artifact-validation/runtime-server typecheck`
- `pnpm --filter @artifact-validation/runtime-server test`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
