# v0.1.0-alpha.2

> Date: 2026-04-29
> Status: Windows clean-checkout fix release
> Supersedes: `v0.1.0-alpha.1`

## Why This Release Exists

Windows clean-checkout testing found two release blockers in `v0.1.0-alpha.1`:

- `pnpm typecheck` could fail before `dist` existed because workspace package exports pointed at generated declarations.
- Some package test scripts used shell glob patterns that were not stable on Windows.

## Fix

- Root `pnpm typecheck` now uses TypeScript build mode so project references are resolved in dependency order.
- Package-level `typecheck` scripts use build mode as well.
- Vitest has workspace source aliases so tests can run before package `dist` output exists.
- Package-level test scripts use the `test` directory instead of shell-expanded globs.

## Expected Windows Flow

```text
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

Then continue with the fake Runtime smoke test in `WINDOWS-TEST-RUNBOOK.md`.
